# Anexos del Incremento 4

Guardar aquí la documentación complementaria real y definitiva.

- `Pruebas/`: planes, resultados y evidencias.
- `Arquitectura/`: modelo de datos, diagrama de componentes, despliegue y árbol de navegación finales (si fueron actualizados).
- `Gestion_y_Trazabilidad/`: backlog, Scrum++, riesgos, responsables, commits y trazabilidad.
- `Instalacion/`: documento de instalación e instrucciones de ejecución.
- `Aceptacion_Contraparte/`: aprobación del cliente/carta de aceptación.

No almacenar contraseñas ni datos reales confidenciales de la empresa.
